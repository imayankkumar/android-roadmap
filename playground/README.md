# Playground

Free space to try things while reading a post or watching a video. Nothing here is tested.

1. Write any Kotlin in [Playground.kt](src/main/kotlin/Playground.kt) and run `main()` from the IDE.
2. See the Java: **Tools > Kotlin > Show Kotlin Bytecode > Decompile**, or run `./gradlew :playground:decompile` and open `playground/decompiled/` (not committed).
3. Want to see a compiler error from a post? Copy a file from any topic's `wont-compile/` folder in here.
